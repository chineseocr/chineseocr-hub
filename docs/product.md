# 产品功能

ChineseOCR Hub 将多模态识别、业务配置、结果核对和应用发布放在同一工作台中。

## 使用流程

- 通用识别：连接模型 → 上传图片/PDF → 全文、表格或多文档识别 → 核对来源 → 导出。
- 业务提取：创建应用 → 配置字段/提示词/字典 → 保存版本 → 样本调试 → 数据集评测 → 发布 API。

## 功能模块

| 模块 | 用途 |
|---|---|
| 应用管理 | 检索、分类、复制、导入导出、安装 17 套证件配置、版本对比与发布 |
| 提取工作台 | 全文、表格、多文档和自定义字段识别；PDF 页签、图像缩放与来源联动 |
| 字段与表格 | 配置普通字段、对象分组、明细数组及可选值 |
| 提示词版本 | 编辑系统/用户提示词、预览变量渲染、保存不可变版本 |
| 字典管理 | 维护可选值版本，复制到字段 enum 形成应用快照 |
| 数据集与评测 | 管理样本和标准答案，比较字段结果与配置版本 |
| 任务记录 | 查看状态、来源、结果和用量；取消或重新运行 |
| 模型接入 | 配置模型服务、发现模型、选择请求参数模式 |
| 团队与平台管理 | 在线模式的账户、成员、角色、API Key、额度与操作审计 |

## 结构与版本

根 Schema 为 object，可包含 KV、分组对象及明细数组。表格列使用 `array.items.properties` 定义；每个分组可以拥有自己的字段和明细。字段支持空值、必填规则及字典枚举。

字段与提示词一起保存为应用版本。字典复制形成快照；发布固定应用版本、模型连接和处理策略。新草稿不改变已有发布，历史发布可以重新激活。

## PDF 与结果核对

全文、表格和多文档逐页处理；自定义字段支持逐页或每文件联合提取。字段来源位置与业务 JSON 分开保存，支持页面、字段和图像框双向选择。运行参数及页数限制见 [功能与限制](ocr-capabilities.md)。

## 评测

标准答案采用 JSON 叶子字段精确比较：字符串按原值比较，数组按位置对齐；缺失、null 和空字符串分别处理。额外输出字段单列。运行固定应用版本、模型选择和样本快照，没有标准答案时不计算准确率。操作步骤见 [使用案例](../examples/use-cases.md#9-比较提示词版本)。

## 规划方向

- 高分辨率小字处理、方向与透视校正。
- 人工纠错、跨页续表及业务合并规则。
- 细粒度评测、样本编辑与数据保留策略。
- 独立 worker、PostgreSQL、对象存储及多实例部署。
- SSO 与订阅计费。

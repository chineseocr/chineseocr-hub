# Third-party dependencies

ChineseOCR Hub source and generated examples are licensed under Apache-2.0. This does not relicense dependencies, Python, container images, model services or model weights.

Direct runtime dependencies pinned in requirements.lock:

| Dependency | Version | Upstream-declared license metadata |
|---|---|---|
| FastAPI | 0.163.2 | MIT |
| Uvicorn | 0.54.0 | BSD-3-Clause |
| HTTPX | 0.28.1 | BSD-3-Clause |
| python-multipart | 0.0.34 | Apache-2.0 |
| Pydantic | 2.14.3 | MIT |
| Pillow | 13.0.0 | MIT-CMU; bundled components have additional notices |
| pypdfium2 | 5.15.2 | BSD-3-Clause / Apache-2.0; PDFium and bundled dependencies have additional licenses |
| jsonschema | 4.26.0 | MIT |
| cryptography | 50.0.2 | Apache-2.0 OR BSD-3-Clause; bundled OpenSSL notices apply |

This table reports installed package metadata, not a claim that every binary component uses only that single license. `docs/dependencies.json`, generated by `scripts/dependency_inventory.py`, lists the installed runtime dependency graph, versions, declared metadata and included license file locations. `requirements.lock` pins distribution hashes. Platform-specific binary components and their license files must be preserved when distributing wheels or images.

Keep cryptography's distribution license files, bundled OpenSSL notices and the notices of its cffi/pycparser dependencies. In particular, keep pypdfium2's installed `*.dist-info/licenses/LICENSES` and `BUILD_LICENSES` trees, including PDFium's notices and the notices of the components actually bundled in the wheel. Keep Pillow's distribution license/notice files and its bundled library notices. The Dockerfile uses normal pip wheel installation and does not strip these files. The source archive contains no third-party wheels or native binaries.

The Python base image and operating system packages retain their own notices. The source Dockerfile uses a public Python 3.12 image tag; it is not an immutable image digest. Deployment maintainers should pin and verify the digest for their published release and target architecture.

Model services and weights are configured separately and retain their own licenses. Example images/PDFs are generated by scripts/generate_examples.py. The UI uses system fonts and project CSS/JS without an external CDN; system font files are not distributed.

Development tools (pytest, Ruff, pip-audit and their dependencies) are installed only for validation, not into the runtime Docker image. Their licenses remain with their upstream distributions. Preserve upstream notices if repackaging them.

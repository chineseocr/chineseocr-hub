# 识别功能与使用限制

适用版本：v0.6 Alpha。所有识别能力使用配置的多模态模型，支持 Web、HTTP API、CLI 和 Python 库。接入步骤见 [模型教程](model-connections.md)。

## 识别能力

| 功能 | 用法 |
|---|---|
| 全文 OCR | 无需定义字段，输出纯文本、Markdown、文字块和来源位置 |
| 通用表格 | 提取页面 KV、表头、表体及合并跨度，导出 CSV / HTML |
| 多文档 | 同图定位、分类、裁剪并分别识别；可按类别绑定字段应用 |
| 自定义字段 | 使用 JSON Schema、系统/用户提示词及字典枚举提取业务 JSON |
| PDF 核对 | 按页签切换，字段、文字块和表格单元格联动来源框 |
| 图像处理 | EXIF 方向归一化、手动旋转、可选小角度纠偏与上下文定位 |
| 数据集评测 | 按标准答案比较叶子字段，查看版本差异、失败项及模型用量 |
| 应用 API | 发布固定版本，通过应用编码提交任务，使用团队及应用范围密钥 |

示例见 [使用案例](../examples/use-cases.md)，表格结构与导出见 [表格指南](tables-and-localization.md)。

## 输入与运行上限

| 项目 | 限制 |
|---|---|
| 格式 | PNG、JPEG、WEBP、单页 TIFF、PDF |
| 单文件 | 20MB；图片最多 1600 万像素 |
| PDF | 最多 20 页；预览最长边 1600px |
| 联合字段提取 | 每文件最多 8 页，输出一个业务 object |
| 单任务 | 最多 5 个文件、20 个输入页处理单元 |
| 多文档 | 每页最多 12 个实例 |
| 通用表格 | 每页最多 10 表、3000 个单元格；每表最多 300 行、60 列 |
| 数据集 | 每集最多 50 个样本，数组按位置比较 |
| 部署 | 每数据目录一个进程；SaaS 最多 100 团队、全平台 4 个在途模型调用 |

## 结果与处理规则

- 全文、表格和多文档逐页处理。自定义字段可选逐页或每文件联合提取；独立文件分别输出。
- 模型位置通过 0–1000 归一化坐标映射到来源；未返回有效位置时为 `null`。置信度字段为 `null`。坐标字段见 [坐标处理](coordinate-processing.md)。
- 精细定位默认每页/实例最多追加 4 批调用。页额度与模型请求次数、模型词元用量分别记录。
- 任务保留逐页/逐实例检查点。取消在处理单元之间生效；重启时尚未保存的在途请求可能再次调用。
- 证件配置用于字段提取，不提供防伪、身份核验或正反面自动配对。

## 暂不支持

自动 90° 内容方向检测、透视矫正、跨页续表与跨文件业务合并、XLSX / 可搜索 PDF、人工修改结果回写、多实例共享数据目录、SSO 和订阅计费。

业务上线前可按 [评测案例](../examples/use-cases.md#9-比较提示词版本) 比较目标场景的数据集。开发验证与运行命令见 [测试文档](validation.md)。

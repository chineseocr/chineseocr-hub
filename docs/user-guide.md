# ChineseOCR Hub 操作手册

[English](user-guide.en.md) · [Docker 部署](docker.md) · [字段/提示词/字典说明](configuration.md) · [API](api.md)

适用版本：**v0.6.0a1 Alpha**。本手册按首次使用顺序说明操作；模型服务需要另行部署或购买。所有视觉识别均使用你配置的多模态模型。

## 1. 登录与选择团队

先按 [README](../README.md) 或 [Docker 指南](docker.md) 启动后端，通过 `http://127.0.0.1:8765/?lang=zh` 访问，不能直接打开静态 HTML 文件。

- 社区版：使用私有 `access-token` 或运维设置的 `WORKBENCH_TOKEN` 登录，持有者拥有整个工作空间的管理权。
- 在线版：使用账户登录，确认当前团队后再配置、上传。团队间不共享应用、模型连接和文档。viewer 只读；member 可运行与编辑草稿；admin/owner 可配置模型和发布应用。
- 页面可切换中文/English；切换只影响系统文案，不改写业务提示词、字段名称、文件名或模型结果。

## 2. 连接模型并完成第一次识别

还没有模型服务？先按 [模型接入教程](model-connections.md) 选择 OpenAI API 或自部署 Qwen-VL，包含页面逐项填写示例。

1. 进入「模型接入」，填写服务 Base URL 和所需 API Key，检测连接并选择服务实际返回的模型 ID，保存连接。在线版该步骤需要团队 admin/owner，地址必须被平台允许。
2. 进入「提取工作台」，选择该模型连接与「全文 OCR · 多模态识别」。
3. 从项目 `examples/` 上传 `synthetic-invoice.png`，选中该文件，点击「开始提取」。示例须手动上传，镜像不预装样本或答案。
4. 等待任务完成，在结果区核对结构化文字块、全文与 JSON，点击文字块检查左侧来源框，再下载文本或 JSON。

首次验证建议使用合成文档。模型列表可读取不等于支持视觉；上传识别会将页面 PNG 和提示词发送到所选服务。

## 3. 按任务选择识别方式

| 你的目标 | 工作台识别能力 | 是否需要应用字段 |
|---|---|---|
| 获取整页文字/Markdown | 全文 OCR | 否 |
| 提取任意表格，同时保留页面 KV | 通用表格识别 | 否 |
| 一张图上有多张证件/票据 | 多证件 / 混合文档 | 可选，为各类别配置字段应用路由 |
| 按固定业务字段输出 JSON | 自定义字段提取 | 是，先新建应用并保存版本 |

自定义字段模式使用所选应用的字段结构。为文档选择对应的应用；未出现的字段返回 `null`。

## 4. 通用表格、表头与页面 KV

1. 上传 `examples/synthetic-table.png`，选择「通用表格识别」。
2. 展开运行配置，按需启用小角度纠偏或精细定位，运行任务。直接定位用于首次验证；精细定位默认每页最多追加 4 批模型请求，会增加耗时和费用。
3. 结果区分别查看页面 KV 和表格，表格保留多行表头、表体及模型/几何辅助确认的合并跨度。
4. 点击 KV 或单元格定位来源；点击图像框反向选中结果。未返回有效坐标时显示无坐标。
5. 下载表格 CSV 或 HTML。HTML 保留合并跨度，CSV 适合数据交换，不保留视觉合并格式；当前不导出 XLSX。

小角度纠偏覆盖 ±8° 范围，不是自动 90° 方向检测或透视矫正。线框辅助只在单张清晰直线表格满足条件时使用，不能保证所有表格结构正确。详见 [表格与定位](tables-and-localization.md)。

## 5. 多页 PDF 与来源核对

上传 `examples/synthetic-table-multipage.pdf`，运行通用表格。完成后，结果区按页签切换页面，左侧预览同步到对应来源页；多文件任务的页签包含文件信息。

- 页范围留空表示全部页，也可输入 `1-3,5`。PDF 最多 20 页；联合字段提取每文件最多 8 页。
- 全文、通用表格和多文档按页处理；自定义字段可选择逐页或整份文档联合提取。独立文件不互相合并。
- 来源支持适应宽度、缩放和显示/隐藏框；结果与图像可分别滚动。点击字段/文字块/单元格与点击来源框可双向联动。
- 在「任务记录」重新打开已完成任务，核对时看的是该任务的固定配置和输入，而非后来修改的草稿。

位置映射到原图像素或 PDF points，详见 [坐标说明](coordinate-processing.md)。没有自动跨页续表合并或人工修改结果回写；页面联动用于核对，不是已完成校正的证明。

## 6. 新建身份证应用及管理大量提示词

1. 进入「应用管理」，点击「安装常用证件配置」，或新建应用时选择「身份证正面」。安装后的配置是可编辑草稿，不自动发布。
2. 搜索身份证应用并进入字段/提示词入口，确认姓名、号码、住址等字段与当前图像面一致。正反面采用不同配置。
3. 在「提示词版本」编辑系统和用户提示词。保留用户提示词的 `{{schema}}`；可使用 `{{filename}}` 和 `{{pages}}`。保存新版本。
4. 回到工作台选择对应应用、版本和模型连接，使用有授权样本调试。看不清的内容应返回 `null`，不要用真实号码推算其他字段。

每种场景对应一个应用，应用编码作为稳定调用入口。100 种以上场景可按编码/名称/标签/负责人搜索，按分类和状态过滤并分页。复制应用用于创建独立场景；版本对比用于评估修改；配置导入导出用于迁移，不包含模型密钥或文档。详情见 [应用管理](applications.md)。

17 套证件配置提供可编辑字段与提示词；证件防伪和身份核验不属于字段提取功能。

## 7. 配置「表头 KV + 表体明细」及字典

业务格式固定时，使用自定义字段提取，在「字段与表格」配置：

- 普通字段：单据编号、日期、供应商、总额等页面 KV。
- 对象分组：购买方/销售方等分组下的姓名、地址、税号。
- 对象数组：明细表，每行的子字段就是列，如商品、数量、金额；列字段说明可填写实际表头和提取规则。

也可导入 [分组报销 Schema](../examples/grouped-expenses.schema.json)。字段类型允许 `null` 时，`required` 只要求 key 存在，不要求识别出非空值。

在「字典管理」保存可选值版本，再通过字段右侧「⋯」复制指定版本到字段 `enum`。字典复制形成快照；后续更新字典不会自动改变已保存应用。允许空值时，字段类型和枚举都须包含 `null`。系统校验不在枚举内的输出，但不会偷偷替换模型结果。

## 8. 一张图上的多张证件

工作台选择「多证件 / 混合文档」，可为身份证、发票等类别绑定相应应用版本。先由模型定位，再实际裁剪各实例，分别全文识别或按类别应用提取字段；同类多张也分别保留 ID、来源框和结果。

多文档视图默认显示各文档的边界框；点击或悬停某条文字/字段时，再显示它在原图上的位置。未配置路由的类别执行全文识别。最多 12 实例/页；不是正反面自动配对。一页通常有一次定位调用，再为每个实例调用识别，必要时还会追加精细定位；不能按“一页一次请求”估算全部模型费用。

## 9. 数据集与评测

1. 先保存待验证的字段应用版本，并上传样本文件。
2. 进入「数据集与评测」，新建数据集，展开「添加带标准答案的样本」，选择文件。
3. 填写单个业务 JSON 对象，或导入标准答案文件，点击「添加到数据集」。初次练习可配对 `synthetic-invoice.png` 与 `synthetic-invoice.gold.json`，并使用匹配的票据字段结构。
4. 选择模型、应用版本和运行模式，运行评测，查看逐字段差异并下载报告。
5. 修改提示词后保存新版本，在同一标准答案快照上重跑；勾选两条记录比较。

最多 50 样本/数据集。分数是业务 JSON 叶子字段精确匹配率；失败、缺失字段计入分母，数组按位置比较。它不是全文字符准确率、坐标 IoU 或通用表格评测。不要给通用表格结果套用票据标准答案后把分数当成表格质量指标。

## 10. 发布应用供外部系统调用

1. 在「应用管理」选择已验证的应用版本、模型连接和发布识别能力（自定义字段/全文/通用表格），设置定位策略并发布。在线版需要 admin/owner 会话。
2. 在线版创建仅限该应用的 API Key，私下交给调用方；Key 明文只显示一次。
3. 调用方通过 `POST /v1/files` 上传，`POST /v1/apps/{code}/recognitions` 提交，再轮询 `GET /v1/jobs/{id}`。完整可复制示例见 [API 操作](applications.md#公开识别-api)。

发布固定字段、提示词、模型连接选择及处理策略；保存新草稿不改变线上发布。需要生效时发布新版本，需要回退时激活历史发布。停用阻止新提交，不删除历史结果。调用方不能覆盖提示词或模型地址。

## 11. 失败、取消与运行成本

在「任务记录」查看排队、运行、完成、部分完成、失败和取消状态。`partial` 表示已有可用结果同时存在失败或未确认内容，须检查具体单元；保存原始输出有助于排查，不应将其当成经过审核的数据。

取消是协作式，已经发送的模型请求无法撤回。重启可复用已落库检查点；中断时尚未落库的调用可能再次发送并计费。模型错误不自动重试，手动重跑会新增调用。页额度与模型请求数/账单不是一回事，usage 只统计模型实际报告的用量。
